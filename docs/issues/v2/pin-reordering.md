Bottom-bar pins use `nav_order`, but it's auto-assigned by catalog order on save.
There's no way to manually reorder the (≤3) pinned features.

## Scope
- Drag-to-reorder (or up/down) for pinned features in the Event Features config, writing `nav_order`.

## Acceptance
- An admin can control the left-to-right order of the bottom-bar pins.
